# What Is the Projects Folder

The Projects folder is for focused, well-defined efforts toward some specified outcome (i.e., “projects”). By definition, any note that can go in the Projects folder should be categorizable into an appropriate child folder, as it should be part of a specific initiative.

When a project is done, its related materials should be filed to one of the following:

- **Documentation** folder: For materials that need to be referenced indefinitely
- **Archive** folder: For materials that could be useful at some point, but no immediate need is seen to make them referenceable.
- **Trash**: For materials that will definitely serve no purpose beyond the project.

For materials filed to **Documentation** or **Archive**, it will usually make sense to add a folder for the project, or a folder to contain materials from similar projects.
