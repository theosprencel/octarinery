# What Is the Inbox Folder

Similar to a quick capture or “brain dump” folder, the **Inbox** folder is for quick notes that are not ready to be processed, filed and/or categorized more defnitively.

It is like an email inbox, with the key difference being that I have decided what ends up here (because I decide what ends up in my notes entirely). Instead of the notes being “unread” they are more like “unprocessed.”

## What goes in the Inbox folder?

Any notes that are not ready to go in the Notes, Projects, Documentation or Archive folders.

## What does *not* go in the Inbox folder?

The easiest way to gauge this is to ask if the note is in Reviewing, Revising or Done for the **Status** property. If it can considered any of those statuses, it does not belong in the Inbox (except for this one exception, which is filed here to explain how to use the folder).
