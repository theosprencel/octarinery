# Folders Guide

My personal folder system started with the PARA Method ( [[5. Archive/What is the PARA Method]] ) but I adapted it a little bit for what suits my workflows, use cases and how I tend to think about things. This is a brief overview of the folders and quick guide to using them.

| Folder | Alias(es) | Use It For | Do Not Use It For | Comments |
| --- | --- | --- | --- | --- |
| **Inbox** | Quick Capture | Quick capture or "brain dump" notes; any other notes that aren't clear where to file. | Long-term storage. If a note hasn't been processed after a couple days, deal with it or trash it. | Similar in some ways to the email sense of "inbox" but here it will only contain items by my choosing. |
| **Notes** |  | Notes that arise from day-to-day work and activities; notes in the traditional sense. | 1. Notes that are tied to specific projects (file in the appropriate folder under **Projects** parent).<br><br>2. Finalized, longer-form notes.
